    Road network¶

    The road network of the traffic assignment is built from OpenStreetMap and checked against three MDOT State Highway Administration (SHA) inventories. This page describes the source data and the attributes of the 2024 network that MILES uses. The construction steps are summarised in Zone system and networks.

    OpenStreetMap, Maryland extract¶

    Source. OpenStreetMap contributors, Maryland extract distributed by Geofabrik [22], in PBF format (212 MB; replication timestamp 11 June 2026). Licence: Open Database Licence. The extract is converted with pt2matsim to a MATSim network in EPSG:26985 (NAD83, Maryland, metres).

    Codebook¶

    Variable Description Type Values / categories / units Used in
    highway Road class of the way string motorway, trunk, primary, secondary, tertiary, unclassified, residential, living_street, service; _link for ramps Link class, default lanes, capacity per lane, speed rules
    maxspeed Posted speed limit string e.g. 35 mph; missing on most minor roads Free speed (rule a)
    lanes Number of lanes of the way integer (string) 1–8; missing on most minor roads (class default used) permlanes, capacity
    oneway Direction of travel string yes, no, -1, alternating; missing = two-way except motorways One or two links per way
    name Street name string free text Matching of count stations and speed rule c
    way id OSM way identifier integer — Join of tags to links
    node coordinates Longitude, latitude of nodes float WGS84 degrees, projected to EPSG:26985 Link geometry and length
    motorway_junction ref Exit number at a junction node string e.g. 27A Interchange checks

    Processing¶

    • Ways with a highway tag of the classes above, and railway ways used by transit, are converted with pt2matsim; the Francis Scott Key Bridge is closed in the 2024 network (closure of 26 March 2024).
    • Freeway and ramp capacities come from Highway Capacity Manual bottleneck values; non-freeway classes are raised to the MDOT functional class where MDOT rates the road higher, never lowered.
    • Free speed of surface streets = posted speed × 0.9 below 51 km/h, × 1.0 otherwise; capacity = capacity per lane of the class × max(lanes, 1) (MATSim OSM reader defaults). The posted speed is the first available of:

    MDOT SHA road inventories¶

    Source. MDOT State Highway Administration open data portal [23]: Roadway Functional Classification, Roadway Lane Mileage, Roadway Sign Inventory (posted speed-limit signs) and Roadway Interchange Exits, downloaded with the ArcGIS REST service of each layer for the bounding box of the network area (EPSG:26985). They are used to check and correct the OSM class, lanes and speeds; they are not a network themselves.

    Processing¶

    • A link is matched to the nearest MDOT centreline within 20 m whose bearing is within 30 degrees; OSM classes map to MDOT groups (motorway 1–2, trunk 2–3, primary 3, secondary 4, tertiary 5–6, minor roads 7).
    • Through lanes are mainline lane-miles divided by segment length, halved on two-way roads; they are compared with permlanes and reported per link, not used to recode lanes.
    • A sign is attached to the nearest car link within 30 m with the same travel direction.
